# [EPIC] demo-dumpkeys supports multi-octet inputs, and supports broken sequences

## Requirements

* [ ] [VtInputSource supports multi-octets inputs, and supports broken sequences](./010.md)
* [ ] [VtInputFromCharacters supports multi-octets inputs, and supports broken sequences](./011.md)

## References

* [VtInput](../00-specs/VtInput.md)

## Behaviours

> To be tested manually

### It should display input of type "key" -- multi-octet

**Given** `demo-dumpkeys` is started

**When** typing the arrow key up

**Then** `demo-dumpkeys` prints : `keys : ARROW UP`

### It should display support broken ANSI sequence

**Given** `demo-dumpkeys` is started

**When** typing the ESCAPE key

**Then** `demo-dumpkeys` prints : `keys : ESCAPE`

> A multi-octets sequence MUST be available without failed data reading from stdin. By pressing the ESCAPE key,
> it starts an ANSI escape sequence, but there is no follow-up data, meaning the sequence is broken.
