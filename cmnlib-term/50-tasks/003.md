# [EPIC] demo-dumpkeys supports single-octet inputs

## Requirements

* [ ] [VtInputSource supports single-octet inputs](./008.md)
* [ ] [VtInputFromCharacters supports single-octet inputs](./009.md)

## References

* [VtInput](../00-specs/VtInput.md)

## Behaviours

> To be tested manually

### It should display input of type "printable" -- US-ASCII

**Given** the encoding of the terminal is `utf-8`

**Given** `demo-dumpkeys` is started

**When** typing the US-ASCII character "a"

**Then** `demo-dumpkeys` prints : `printable : 97 ('a')`

### It should display input of type "printable" -- non US-ASCII

**Given** the encoding of the terminal is `utf-8`

**Given** `demo-dumpkeys` is started

**When** typing the US-ASCII character "é"

**Then** `demo-dumpkeys` prints : 

```
printable : 195
printable : 169
```

### It should display input of type "key" -- mono-octet

**Given** `demo-dumpkeys` is started

**When** typing the combination CTRL+B

**Then** `demo-dumpkeys` prints : `keys : CTRL+B`

**When** typing the combination CTRL+M or the RETURN key

**Then** `demo-dumpkeys` prints : `keys : RETURN`
